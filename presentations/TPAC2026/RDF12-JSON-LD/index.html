JSON-LD direction

In 1.1 mapped to either rdf:CompoundLiteral or special i18n: datatype 

<html_and_css>
  dct:title [ a rdf:CompoundLiteral ;
      rdf:value "HTML و CSS: تصميم و إنشاء مواقع الويب" ;
      rdf:language "ar" ;
      rdf:direction "rtl"
    ] .
<html_and_css>
  dct:title
    "HTML و CSS: تصميم و إنشاء مواقع الويب"^^i18n:ar_rtl .
{
  "@id": "html_and_css",
  "dct:title": {
    "@value": "HTML و CSS: تصميم و إنشاء مواقع الويب",
    "@language": "ar",
    "@direction": "rtl"
  }
}

RDF 1.2 direction

RDF 1.2 direct representation: rdf:dirLangString 

<html_and_css>
  dct:title
    "HTML و CSS: تصميم و إنشاء مواقع الويب"@ar--rtl .

To be rendered as:
HTML و CSS: تصميم و إنشاء مواقع الويب 

{
  "@id": "html_and_css",
  "dct:title": {
    "@value": "HTML و CSS: تصميم و إنشاء مواقع الويب",
    "@language": "ar",
    "@direction": "rtl"
  }
}

RDF Annotation

<Alice> :bought <LennyTheLion> {|
    a :Purchase ;
    :seller <ToyStore> ;
    :date "2026-10"
  |} .

Plain assertion

<Alice> :bought <LennyTheLion> .
{
  "@id": "Alice",
  "bought": {
    "@id": "LennyTheLion"
  }
}

Annotation Sugar

<Alice> :bought <LennyTheLion> {|
    a :Purchase ;
    :seller <ToyStore> ;
    :date "2026-10"
  |} .
{
  "@id": "Alice",
  "bought": {
    "@id": "LennyTheLion",
    "@annotation": {
      "@type": "Purchase",
      "seller": {"@id": "ToyStore"},
      "date": "2026-10"
    }
  }
}

Reifiers & Triple Terms in JSON-LD 1.3

  1. One proposal is to introduce two new keywords: @reifies and @triple used as keys (and the latter indicating a new kind of node), directly corresponding to the RDF terms.
  2. Another is to define one keyword (such as @quote), used as key in reifiers and as @type value for triple terms (leveraging the existing @value node design).
  3. A third is to reuse the @graph keyword, otherwise following the @quote design.
